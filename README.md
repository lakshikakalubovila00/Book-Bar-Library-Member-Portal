Book Bar Library Member Portal

A web-based member portal for the Book Bar Library Management System that allows library members to conveniently access library services and manage their activities online.

✨ Features

🔐 Member Login & Authentication
📚 Search Books
🔎 View Book Details and Availability
📖 View Borrowed Books
🔄 View Borrowing History
📌 Reserve Books
📋 View Reservations
📌 Renew Books
👤 View Member Profile

🛠️ Technologies Used

- Backend: Java 21, Spring Framework, Spring Boot
- Frontend: HTML5, CSS3, JavaScript, Bootstrap 5, jQuery
- Database: MySQL 8.0
- Build Tool: Gradle
- Development: IntelliJ IDEA
- Design & Modeling: Figma, Visual Paradigm
- Version Control: Git & GitHub
